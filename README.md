# SchoolCom — оформление источников

Android-приложение для студентов: оформляет список литературы и ссылки
по ГОСТ Р 7.0.100-2018 / ГОСТ Р 7.0.5-2008 и по правилам ВКР НИУ ВШЭ.

План работ — в [docs/PLAN.md](docs/PLAN.md).

## Структура

- `core/` — правила оформления на чистом Kotlin (без Android) и тесты.
- `app/` — Android-приложение на Jetpack Compose.

## Запуск

Откройте папку проекта в Android Studio и запустите конфигурацию `app`.

Тесты правил оформления: `./gradlew :core:test`.

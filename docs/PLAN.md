# SchoolCom — оформление источников по ГОСТ и правилам ВКР НИУ ВШЭ

Android-приложение для студентов: пользователь вводит данные об источнике (или находит
его по DOI / ISBN), а приложение выдаёт готовую библиографическую запись для списка
литературы и ссылку для текста работы.

## Решения

| Вопрос | Решение |
|---|---|
| Платформа | Android, проект для Android Studio |
| Язык и UI | Kotlin, Jetpack Compose, Material 3 |
| Пользователи | студенты (КР, ВКР) |
| Языки источников | русский и английский |
| Стили | ГОСТ Р 7.0.100-2018 и ГОСТ Р 7.0.5-2008; профиль «ВКР НИУ ВШЭ» |
| Ссылки в тексте | затекстовые `[1, с. 25]`, `[Иванов, 2020, с. 25]`, подстрочные, «Там же» / «Ibid.» |
| Автозаполнение | по DOI (Crossref) и ISBN (Open Library / Google Books) |

## Архитектура

```
core/   чистый Kotlin (без Android): модели, правила оформления, тесты
app/    Android-приложение (Compose): экраны, хранение списка, экспорт
```

Правила оформления живут в `core`, поэтому их можно покрыть юнит-тестами и
проверять без эмулятора. Стиль — это набор настроек `StyleOptions` поверх общего
форматтера ГОСТ, поэтому профиль ВШЭ отличается от «чистого» ГОСТа только
параметрами (порядок групп, «Текст : электронный», число авторов до «[и др.]» и т. п.).

## Правила (ядро)

- ГОСТ Р 7.0.100-2018 — библиографическая запись: разделители `. – `, ` / `, ` // `,
  ` : `, ` ; `; инициалы с пробелом (`И. И.`); тире `–` в диапазонах страниц.
- Авторы: 1–3 — запись под первым автором, за `/` перечисляются все; 4 и более —
  запись под заглавием, за `/` первые три и `[и др.]` / `[et al.]` (порог настраивается).
- Английские источники: `Vol.`, `No.`, `P.`, `p.`, `ed. by`, `[et al.]`.
- ГОСТ Р 7.0.5-2008 — ссылки: затекстовые в квадратных скобках, подстрочные
  (полная запись с конкретной страницей), повторные «Там же. С. 25.» / «Ibid. P. 25.».
- Список: сначала источники на кириллице, затем на латинице, по алфавиту;
  в профиле ВШЭ нормативные акты выносятся в начало списка.

### Типы источников

1. Книга (авторы, редакторы, издание, том, место, издательство, год, страницы, ISBN)
2. Статья в журнале (том, номер, страницы, DOI)
3. Статья в сборнике / глава в книге
4. Электронный ресурс / сайт (URL, дата обращения)
5. Диссертация и автореферат
6. Нормативный правовой акт

## Этапы

1. **Ядро** — модели, форматтер ГОСТ для всех 6 типов, профиль ВШЭ, ссылки в тексте,
   сортировка списка, тесты на эталонных примерах. *(сделано)*
2. **Приложение** — экран списка, форма источника (поля зависят от типа), выбор стиля,
   копирование записи и всего списка, сохранение списков (Room).
   *(каркас сделан: список, форма с предпросмотром, выбор стиля, копирование; нет сохранения)*
3. **Автозаполнение** — DOI через api.crossref.org, ISBN через Open Library / Google Books,
   предупреждения о незаполненных обязательных полях.
4. **Экспорт** — .docx (Times New Roman 14, полуторный интервал) и .txt; «Поделиться».
5. **Доработка** — импорт BibTeX/RIS, патенты, стандарты, многотомники, тёмная тема.

## Открытые вопросы

- Точные требования ВКР зависят от образовательной программы ВШЭ. Профиль «ВШЭ» пока
  собран по общим требованиям (ГОСТ Р 7.0.100-2018, кириллица → латиница, НПА в начале,
  нумерованный список). Нужен текст «Правил подготовки ВКР» конкретной программы,
  чтобы сверить и уточнить профиль.
